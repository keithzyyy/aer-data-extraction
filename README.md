# Project Goal

Before proceeding to an interview we have a small test to understand your data handling capabilities.

A lot of data in the energy sector is semi-structured. It lives in excel spreadsheets designed for presentation in a word document but not great for entry into a database.

- Your task involves extracting, structuring and presenting data which can be found in the AER's RIN workbooks. The AER's website is https://www.aer.gov.au/
- The businesses that you will extract data from are:
    1. Transgrid
    2. Ausnet transmission
    3. Powerlink
    4. Electranet
    - The templates you need to extract are in the Category Analysis RIN, under 2.8 Maintenance.

The scope of work involves:

1. **Extracting the required RIN data** from each Transmission Business submission for at least the last 5 years
2. **Standardising and structuring** the data to enable cross-business comparison
3. Creating a **consolidated model** suitable for PowerBI
4. **Developing a PowerBI dashboard** to visualise key metrics and insights

You have until Monday 9 am 27 July to complete the task and send back a structured csv and pbix file.
